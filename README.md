# 🎓 AttendanceKeeper v1.0

A desktop GUI application for managing student attendance records built with Python and Tkinter.

## 📸 Screenshot
Screenshot1.png
Screenshot2.png

## ✨ Features
- 📂 Import student lists from Excel files (.xlsx)
- 👥 Section-based student grouping
- ✅ Interactive attendance marking interface
- 📊 Export attendance records to multiple formats (.txt, .xlsx)
- 🎯 Simple and intuitive GUI for educators

### Prerequisites
- Python 3.8 or higher
- pip package manager
